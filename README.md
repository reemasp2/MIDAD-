# مساهمات الواجهة – مِداد | Reemas

هذه الملفات مقتطفة من ملف HTML الأصلي المرفوع للمشروع، وليست إعادة كتابة أو تصميمًا جديدًا. جرى فصل أجزاء الواجهة لتسهيل مراجعتها ورفعها إلى GitHub.

## الملفات

- `01-intro.html` — شاشة الترحيب الافتتاحية.
- `02-home.html` — ترويسة الموقع والصفحة الرئيسية ومحتوى التعريف والخدمات.
- `03-radar.html` — هيكل واجهة رادار الجامعة.
- `04-team.html` — هيكل واجهة كوّن فريقك.
- `05-chat-window.html` — نافذة المحادثة المرئية فقط.
- `styles.css` — تنسيقات الواجهة المشتركة. الملف مأخوذ من ورقة التنسيق الأصلية كاملة لأن التنسيقات متداخلة بين الصفحات.
- `06-radar-interactions.js` — تفاعلات رادار الجامعة الموجودة في المصدر.
- `07-team-interactions.js` — تفاعلات كوّن فريقك الموجودة في المصدر.
- `08-intro-animation.js` — حركة شاشة الترحيب.
- `09-home-lifecycle.js` — تفاعل دورة حياة مِداد في الصفحة الرئيسية.

## ملاحظات دمج مهمة

1. هذه **مكوّنات من مشروع قائم** وليست موقعًا مستقلًا؛ تعتمد على عناصر عامة ودوال وبيانات مشتركة موجودة في التطبيق الأصلي مثل `NEEDS`, `PROJECTS`, `PEOPLE`, `REQUESTS`, `me`, `toast`, `DBX` و`$`.
2. ملفات HTML هنا مقتطفات للدمج داخل بنية التطبيق، وليست صفحات مستقلة تفتح كل واحدة منها مباشرة.
3. ملف `styles.css` يحتوي التنسيقات المشتركة للموقع كله، وليس تنسيقات هذه الصفحات وحدها.
4. لم أضمّن محاكي المسار الأكاديمي ضمن مساهمات الواجهة هنا.
5. لم أضمّن إعدادات خدمة الرد الذكي أو إعدادات قاعدة البيانات؛ المطلوب هنا هو أجزاء الواجهة وتفاعلاتها المرئية.
6. عند الدمج في المشروع الأساسي، لا تضيفوا نفس الـ IDs أو ملفات CSS/JS مرتين.

## طريقة الرفع

ارفعي مجلد `midad-reemas-ui-contributions` إلى مستودع GitHub، أو انسخي الملفات إلى مجلد مثل `src/reemas-ui/` داخل المستودع المشترك. قبل دمجها في نسخة التشغيل، على الفريق مراجعة الاعتماديات المشتركة وربطها ببنية المشروع الأساسية.
